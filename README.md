📌 Projects I'm proud of:

🏁 FPV Vision Timer — a camera-based lap timing system as an alternative to RotorHazard. Detects gate crossings from a live video feed instead of RF, with voice callouts and a lap database.

🎯 Vision-guided Nerf turret — YOLOv8 detection driving stepper motors over serial, with pixel-to-motor calibration and configurable target zones.

📺 Walldash — a smart wall display for Raspberry Pi with a plugin widget system, a visual grid editor and 10+ data providers (including live 3D printer status over MQTT).

⚡ Home energy monitor — reads a Belgian Fluvius P1 meter over BLE with an ESP32-C3 and a solar inverter over Modbus TCP, then charts everything on a Pi dashboard.

🕹️ Robotic Connect Four — a 3D printer turned into a game opponent: computer vision reads the board, G-code drops the disc.
